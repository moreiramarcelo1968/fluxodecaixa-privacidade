# Política de Privacidade — Fluxo de Caixa

Este repositório publica a **Política de Privacidade** do aplicativo
**Fluxo de Caixa** (aplicativo de controle financeiro 100% offline), exigida
pela Google Play Store.

- Página publicada: **https://moreiramarcelo1968.github.io/fluxodecaixa-privacidade/**
- Fonte da página: [`index.html`](index.html)

O aplicativo **não coleta nenhum dado**: tudo é armazenado apenas no aparelho
do usuário. Consulte a página para o texto completo.
