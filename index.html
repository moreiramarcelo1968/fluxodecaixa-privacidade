Fluxo de Caixa

Política de Privacidade

Versão 1.0 · 18 de outubro de 2026

Esta política descreve como o aplicativo Fluxo de Caixa (“o aplicativo”) trata os seus dados.

Resumo: o Fluxo de Caixa é um aplicativo de controle financeiro 100% offline. Todos os dados que você informa (lançamentos, categorias, contas, orçamentos) são armazenados somente no seu próprio aparelho. Nada é enviado para servidores ou compartilhado com terceiros.

Dados coletados

Nenhum. O aplicativo não coleta, envia, vende ou compartilha qualquer tipo de dado pessoal, financeiro ou de uso. Não há cadastro, conta ou servidor central: o funcionamento é local, direto no dispositivo.

Dados armazenados no aparelho

Os dados financeiros são mantidos em um banco de dados local, dentro do próprio aplicativo. Eles são usados exclusivamente para exibir e organizar as suas informações na tela.

Permissões do dispositivo

O aplicativo não solicita permissões sensíveis (como contatos, câmera, localização ou microfone).

Compartilhamento

Como não há coleta, também não há compartilhamento de dados com empresas, anunciantes, publicidade ou parceiros.

Exclusão dos dados

Para apagar todos os dados, desinstale o aplicativo (dependendo do sistema operacional, os dados locais são removidos na desinstalação) ou use a opção de exclusão dentro do aplicativo, se disponível.

Crianças e adolescentes

O aplicativo não é direcionado a crianças e não coleta dados de crianças.

Alterações nesta política

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização revista.
